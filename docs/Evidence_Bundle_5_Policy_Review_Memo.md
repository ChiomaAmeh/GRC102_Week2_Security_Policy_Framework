# Evidence Bundle 5: Policy Review and Maintenance Memo

## To

Information Security Steering Committee

## From

Information Security Manager

## Subject

Annual Policy Review and Maintenance Memo

---
 
## Review Triggers

The policy review was triggered by:

1. Migration of the ERP platform to AWS
2. Employee use of personal cloud storage for sensitive information

---

## Review Process

The review involved:

- IT Operations
- DevOps Engineers
- Legal Counsel
- Human Resources

Evidence reviewed included:

- CloudTrail Logs
- ITSM Tickets
- DLP Alerts
- Training Records

---

## Proposed Policy Updates

### Amendment A

Prohibit storage of:

- Source code
- Healthcare information
- Financial records

on personal cloud repositories.

Require:

- OneDrive
- SharePoint
- Approved AWS S3 storage
  
---

### Amendment B

Require:

- Corporate SSO
- MFA
- Infrastructure as Code security scanning
  
Prohibit:

- Direct root account use

---

## Approval Route

1. Information Security Manager
2. IT Director
3. CEO
4. Security Steering Committee

---

Annual review.

Early review triggers include:

- Cloud migrations
- Major incidents
- Regulatory updates
- ISO 27001 changes
- SOC 2 updates
