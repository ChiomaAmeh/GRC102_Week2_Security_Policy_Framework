# Policy Update Summary

## Review Trigger 1

Migration of primary enterprise workloads to AWS cloud infrastructure.

### Governance Impact

- Cloud access management requirements
- Infrastructure-as-Code governance
- Cloud logging and monitoring obligations
 
---

## Review Trigger 2

Employee use of personal cloud storage for sensitive information.

### Governance Impact

- Data protection failures
- Data Loss Prevention requirements
- Acceptable Use Policy updates

---

## Proposed Policy Changes

### Amendment A

Prohibit storage of corporate information within personal cloud services.

### Amendment B

Mandate AWS access through corporate SSO and MFA.

### Amendment C

Require Infrastructure-as-Code security validation before deployment.

---
