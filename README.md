# Repository Overview

This repository contains the complete submission for the GRC102 Week 2 Practical Laboratory.

The assignment focuses on designing and implementing a complete information security policy framework for NexusTech Solutions using governance best practices and the Security Policy Development Lifecycle (SPDL).

The deliverables demonstrate the practical application of:

- Information Security Governance
- Security Policy Development
- Documentation Hierarchies
- Identity and Access Management
- User Awareness and Training
- Security Policy Review and Maintenance
- ISO/IEC 27001 Alignment
- SOC 2 Readiness

---

# Scenario Summary

NexusTech Solutions is a rapidly growing software development organisation that has expanded from 50 to 250 employees.

Following internal governance reviews, management identified significant weaknesses within a legacy "IT Rules" document that mixed:

- Policy statements
- Technical standards
- Operational procedures
- Advisory guidance

The organisation requires a structured policy framework capable of supporting:

- ISO/IEC 27001:2022 readiness
- SOC 2 compliance preparation
- Cloud security governance
- User access management
- Security awareness and training
